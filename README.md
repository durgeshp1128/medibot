# medibot

**MediBot** is an enterprise‑grade intelligent assistant built for **MediAssist Health Network** to streamline knowledge discovery across 12 hospitals and 40+ clinics in India. It indexes clinical guidelines, hospital policies, and equipment manuals while enforcing strict **Role‑Based Access Control (RBAC)** at the database retrieval layer.

## Installation

### Prerequisites

- **Python 3.9+**
- **pip** (Python package installer)
- **Git** (to clone the repository)
- Access to the MediAssist internal network (for database connectivity)

### Steps

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-org/medibot.git
   cd medibot
   ```

2. **Create a virtual environment** (recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows use `venv\Scripts\activate`
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Set up environment variables**
   Copy the example configuration and fill in your credentials:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and provide values for:
   - `DB_HOST`
   - `DB_PORT`
   - `DB_USER`
   - `DB_PASSWORD`
   - `RBAC_SECRET`

5. **Run database migrations** (if applicable)
   ```bash
   alembic upgrade head
   ```

Now the project is ready to be used.

## Usage

The core entry point is the `medibot` CLI. After installation, you can start the assistant with:

```bash
python -m medibot.run
```

### Example Queries

```text
> What is the protocol for managing hypertension in pregnant patients?
```
The bot will retrieve the relevant clinical guideline from the indexed repository and return a concise answer respecting the caller's role permissions.

```text
> Show me the latest MRI safety checklist for the radiology department.
```
The assistant fetches the most recent equipment manual and presents the checklist.

### API

If you prefer to integrate Medibot into another system, import the `MedibotClient`:

```python
from medibot.client import MedibotClient

client = MedibotClient(api_key="YOUR_API_KEY")
response = client.ask(query="List the steps for CPR in adults", role="nurse")
print(response)
```

Refer to the `docs/api.md` (to be added) for a full list of available endpoints.

## Configuration

All configurable parameters are stored in the `.env` file. Key settings include:

- `RBAC_MODE`: `strict` (default) or `lenient`
- `LOG_LEVEL`: `INFO`, `DEBUG`, `WARNING`
- `CACHE_TTL`: cache duration in seconds for query results

Adjust these values to match your deployment environment.
